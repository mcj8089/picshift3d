# Prism Shift 3D

**在线体验 / Play online:** https://pipygames.com/games/prism-shift-3d-ugbi

Prism Shift 3D is a 3×3 wrap-around sliding picture puzzle with a memory twist. Watch the board get shuffled row by row and column by column, then swipe to put the picture back. Twelve hand-illustrated worlds — cosmic launch, coral reef, neon city, lava forge, star whale — each one faster than the last. No blank tiles, no sliding a single piece: you shift whole rows and columns, and they loop around. Free in your browser, portrait-friendly.

## 技术栈 · Tech stack

- 引擎 / Engine: **Three.js**
- 其他 / Also: WebGL 渲染；Canvas 2D 图层
- 语言 / Language: 中文 + English
- 部署 / Hosting: 纯静态，index.html 即入口，直接丢到任意静态空间即可
